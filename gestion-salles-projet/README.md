# gestion-salles

1. Extraire le zip dans un dossier (ex: C:\Users\Admin\IdeaProjects\gestion-salles)
2. IntelliJ : File > Open > choisir le fichier pom.xml > Open as Project > Trust Project
3. Attendre le téléchargement des dépendances Maven
4. Clic droit sur src/main/java/com/example/App.java > Run 'App.main()'
5. Tests : clic droit sur src/test/java > Run 'All Tests'  (ou: mvn test)
